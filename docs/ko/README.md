# 소개

**Jjan (짠)**은 한국의 전통적인 사금융계(곗돈)를 스마트 컨트랙트 기술을 기반으로 재구성한 신뢰 불필요(Trustless) 온체인 순환 저축 플랫폼입니다. 곗돈 회원들이 라운드마다 고정된 금액을 납입하면, 사전에 약정된 순서에 따라 매 라운드마다 한 명의 멤버가 납입금 전액(곗돈)을 수령합니다.

기존의 계모임과 결정적인 차이점은 다음과 같습니다. Jjan 플랫폼에서는 스마트 컨트랙트가 모든 납입금을 에스크로(Custody)하고 약정된 수령자에게 자동으로 지급합니다. 이 시스템에는 관리자 권한(Admin Key)이 존재하지 않으며, 곗돈을 임의로 유출할 수 있는 코드 경로 자체가 없어 기존 계모임에서 흔히 발생하던 계주의 곗돈 유출(Rug)이 원천적으로 불가능합니다.

업비트/두나무의 이더리움 L2인 **GIWA** 네트워크 상에 빌드되어, 여러 멤버들이 매 라운드 반복적으로 수행하는 소액 거래를 속도가 빠르고 수수료가 거의 없는 체인에서 쾌적하게 진행할 수 있습니다.

{% hint style="success" %}
**오늘날 GIWA Sepolia 테스트넷에 배포 및 검증이 완료되었습니다.** 4개의 스마트 컨트랙트가 배포 및 소스 코드 검증 완료되었으며, 128,000회 이상의 무작위 호출(Randomized calls) 테스트를 통해 자산 지급 능력 인바리언트(Solvency Invariant) 검증을 통과했습니다. 자세한 정보는 [배포된 컨트랙트](deployment/deployed-contracts.md) 페이지를 참고하세요.
{% endhint %}

## 한 줄 요약

> 친구들과 온체인에서 함께 저축하세요. 스마트 컨트랙트가 곗돈을 보관하므로 계주가 돈을 가지고 달아날 위험이 전혀 없습니다.

## 주요 차이점 비교

| | 기존 계모임 (KakaoTalk) | Jjan (짠) |
| --- | --- | --- |
| **자금 보관 주체** | 계주 (개인 지갑) | 스마트 컨트랙트 |
| **먹튀 (Rug) 위험** | 계주의 선택에 따른 위험 존재 | 자금 유출 경로 차단 (위험 없음) |
| **거래 기록** | 단톡방 또는 개인 장부 | 모든 거래가 온체인에 영구 기록 |
| **평판 기록** | 멤버들의 기억에 의존 | 연결된 개인지갑의 온체인 평판 점수 |
