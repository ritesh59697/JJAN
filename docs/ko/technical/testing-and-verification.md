# 테스팅 및 검증

Jjan은 스마트 컨트랙트 테스팅 프레임워크인 Foundry를 사용하여 철저히 테스트되었습니다. 단위 테스트(Unit Tests), 퍼즈 테스트(Fuzz Test), 그리고 핸들러 기반의 인바리언트 테스트(Invariant Test)를 수행했으며, 배포된 컨트랙트는 GIWA 블록 익스플로러 상에서 소스 코드 검증(Source-verification)을 마쳤습니다.

## 테스트 스위트 구성

```bash
forge test -vvv
```

**전체 테스트 통과 완료**, 테스트 대상 시나리오:

* **정상 시나리오 (Happy Path):** 3인 규모의 곗방을 개설하여 모든 모임원이 제때 돈을 내고 사전에 지정된 곗돈을 1회씩 정상 지급받은 뒤, 최종적으로 잔여 보증금을 온전히 반환받고 컨트랙트의 잔액이 정확히 0이 되는 전 과정을 검증합니다.
* **자금 유출 방지 검증 (No Admin Drain):** 개설자나 다른 어떤 관리자도 곗돈 에스크로의 자금을 규칙을 위반하여 무단 인출하거나 탈취할 수 있는 수단이 없음을 확인합니다.
* **보증금 삭감 로직 (Slashing):** 라운드 기간 내에 납입을 하지 않은 경우 미납한 멤버의 보증금에서 삭감액이 강제 집행되어 곗돈 풀에 충당되는지와, 평판 점수 변동(미납자 `-1` 점, 정상 납입자 `+1` 점)이 제대로 수행되는지 검증합니다.
* **예외 가드 조건 (Guards):** 라운드가 끝나기 전에 조기 마감을 시도하는 경우, 모든 초대 멤버가 참여하기 전에 곗방을 시작하려는 경우, 초대받지 않은 주소가 가입을 시도하는 경우, 그리고 한 라운드에 중복 납입을 시도하는 예외 상황을 모두 정상적으로 차단하는지 확인합니다.
* **퍼즈 테스트 — 곗돈 보존 법칙 (Fuzz - Pot Conservation):** 임의의 납입 상태 조합(일부 미납, 일부 납입 등)에서도 최종 수령자가 지급받는 곗돈 총액이 '정상 납입금의 합 + 미납자 보증금 삭감액'과 정확히 수학적으로 일치하는지 임의 퍼즈 시나리오(256 Runs)로 검증합니다.

## 지급 능력 불변성 검증 (Solvency Invariant)

```solidity
invariant_Solvency:  token.balanceOf(circle) ≥ circle.obligations()
```

 Foundry의 상태 핸들러(Handler)가 무작위 순서로 `join`, `contribute`, `closeRound`, `withdrawBond`를 수행하여 실제 운영 중인 곗방의 상태를 연속적으로 바꾸며, 모든 트랜잭션 단계가 완료될 때마다 위의 불변식(Invariant) 규칙이 계속해서 굳건히 유지되는지 감시합니다.

{% hint style="success" %}
**테스트 결과: 128,000회 이상의 무작위 상태 변화 호출 테스트에서 단 한 번의 오류나 지급 정지 없이 불변식을 완벽히 만족하였습니다.** 퍼저가 생성한 어떤 임의의 연체/납입 시나리오에서도 컨트랙트는 부도(Insolvent) 상태에 빠지지 않았습니다.
{% endhint %}

## 정적 분석 및 컴파일 설정

* 모든 컨트랙트는 Solidity `0.8.24` 컴파일러 버전 및 옵티마이저(Optimizer) 옵션이 활성화된 청정 상태에서 경고 없이 빌드됩니다.
* 메인넷 배포 전, 스마트 컨트랙트 정적 분석 도구인 Slither(`slither .`) 분석을 전면적으로 거쳐 보안 취약점 사전 감지를 수행합니다.

## 온체인 배포 검증

배포된 4개의 주요 컨트랙트는 모두 GIWA Sepolia 테스트넷에 업로드되었으며 **Blockscout 탐색기를 통해 오픈소스 검증(Source-verified)**을 완료하였습니다. 따라서 블록 탐색기에서 누구나 배포된 컨트랙트의 세부 Solidity 소스 코드를 투명하게 열람하고 감시할 수 있습니다. 각 주소의 목록은 [배포된 컨트랙트](../deployment/deployed-contracts.md) 페이지에 나열되어 있습니다.

GIWA 테스트넷의 가스비 단가(~0.001 gwei)가 매우 낮기 때문에 전체 배포 비용은 **$0**에 가까운 사실상 무료 수준이었습니다.
