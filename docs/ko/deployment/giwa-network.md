# GIWA 네트워크 안내

Jjan은 업비트/두나무의 OP Stack 기반 독자적인 이더리움 레이어 2(L2) 솔루션인 **GIWA Sepolia** 테스트넷 상에서 가동됩니다.

## 왜 GIWA인가?

계모임의 본질은 **여러 사람이 반복적으로 적립하는 다수의 소액 결제**들로 구성된다는 점입니다. 이 같은 금융 행동은 이더리움 메인넷(L1)에서는 가스비 부담으로 운영하기가 불가능하지만, 전송이 매우 빠르고 수수료가 극도로 저렴한 L2 환경에서는 매우 이상적인 사용자 경험을 선사합니다.

* **실시간 수준의 곗돈 수령:** 블록 생성 주기가 약 1초에 불과하며, Flashblocks 엔드포인트를 통해 약 200ms만에 프리컨펌(사전 확인)을 지원합니다. 이 덕분에 라운드를 마감하는 즉시 곗돈이 수령인 지갑에 순식간에 꽂힙니다.
* **초소액 납입 실현 가능:** 가스비 수수료가 거의 0원에 가깝기 때문에 수십 명의 모임원이 라운드마다 소액을 수차례 송금하더라도 수수료에 자금을 낭비하지 않습니다.
* **업비트 생태계 유입 경로:** 한국 중심의 사용자 기반, 친숙한 지갑 경험, 그리고 향후 업비트 거래소 잔고로부터 다이렉트로 온체인 곗방에 저축할 수 있는 잠재적인 경로를 확보하고 있습니다.
