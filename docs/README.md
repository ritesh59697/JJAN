# Introduction

**Jjan (짠)** rebuilds Korea's _kye_ (곗돈) — informal rotating savings clubs — as a
smart contract. Friends contribute a fixed amount each round, and the whole pot
rotates to one member at a time. The difference: the **contract** custodies every
won and pays the scheduled recipient automatically. There is no admin key and no
code path that can divert the pot, so the organizer-rug that plagues traditional
_kye_ becomes impossible.

Built on **GIWA** — Upbit/Dunamu's Ethereum L2 — because a club of many small,
recurring payments only feels good on a fast, near-free chain.

## Why it matters

| | Traditional _kye_ | Jjan |
| --- | --- | --- |
| Who holds the pot | The organizer | The contract |
| Rug risk | One decision away | No drain path exists |
| Record | A group chat | Every round on-chain |
| Reputation | Lives in memory | Follows your wallet |
